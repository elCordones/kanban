# 📋 Projecte Kanban Alumnes

Una aplicació de taulell Kanban senzilla, moderna i persistent, dissenyada específicament perquè els alumnes puguin realitzar el seguiment dels seus projectes educatius.

## 🚀 Característiques

- **Quatre categories de seguiment:** Per fer, En procés, En revisió i Acabat.
- **Persistència local:** Les dades es guarden automàticament al navegador (`localStorage`).
- **Portabilitat total:** Funcions d'**Exportar** i **Importar** en format JSON per poder canviar d'ordinador sense perdre la feina.
- **Multi-idioma:** Suport per a Català, Español, Galego, Euskara i English.
- **Gestió de Temes:** Suport per a mode clar, fosc i automàtic (segons el sistema operatiu).
- **Disseny Adaptatiu:** Funciona perfectament en ordinadors, tauletes i mòbils.

## 🛠️ Instal·lació i Desenvolupament

L'app està construïda amb **React + TypeScript + Vite**.

1. **Clonar el repositori:**
   ```bash
   git clone https://github.com/el-teu-usuari/kanban.git
   cd kanban
   ```

2. **Instal·lar dependències:**
   ```bash
   npm install
   ```

3. **Executar en mode desenvolupament:**
   ```bash
   npm run dev
   ```

4. **Construir per a producció:**
   ```bash
   npm run build
   ```

## 📋 Students Kanban Project (English)

A simple, modern, and persistent Kanban board application designed specifically for students to track their educational projects.

### Key Features:
- **Four tracking categories:** To do, In progress, In review, and Done.
- **Local Persistence:** Data is automatically saved in the browser (`localStorage`).
- **Full Portability:** **Export** and **Import** functions in JSON format to switch computers without losing progress.
- **Multi-language:** Support for Catalan, Spanish, Galician, Basque, and English.
- **Theme Management:** Support for light, dark, and auto modes.
